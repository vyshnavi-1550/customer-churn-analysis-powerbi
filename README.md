# 📊 Customer Churn Analysis Dashboard

## Overview

This project presents an interactive Power BI dashboard to analyze customer churn patterns and identify key factors affecting customer retention. The dashboard helps businesses monitor customer behavior through interactive visualizations and KPIs.

## Features

- Customer churn analysis
- Customer tenure analysis
- Gender-wise customer distribution
- Contract type vs churn analysis
- Partner status analysis
- Dependents vs churn analysis
- Interactive slicers for:
  - Gender
  - Contract Type
  - Internet Service
  - Payment Method

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV

## Key Insights

- Month-to-month contract customers show the highest churn.
- Long-term contracts have significantly lower churn.
- Customer tenure is strongly related to churn behavior.
- Interactive filters enable detailed exploration of customer segments.
